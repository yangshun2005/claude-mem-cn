# 本地 My Work 浏览器验证

验证于 2026 年 10 月 17 日，针对 `http://127.0.0.1:37842/` 和 `http://127.0.0.1:37843/` 的 SQLite 测试夹具服务器。这些服务器仅包含合成记录。浏览器检查期间未更改任何真实记忆数据库、云账户或 agent 对话。

## 结果

已准备好提交候选版本。在已检查的本地视图、审查、交接或窄布局行为中，未发现遗留阻塞问题。

## 已验证行为

- 显式完成的请求显示为 **Ready to check**。标记为已检查会保存本地人工审查，更新计数和交接队列，并将焦点恢复到请求卡片。源生命周期保持独立。
- 保存的检查在页面重新加载后仍然存在。卡片上的 Undo 恢复为 Ready to check。这两个操作本身都不会创建未读工作圆点。
- 新记录的工作一到达就显示，即使请求/源对话框处于打开状态。现有的原始请求和源文本保持不变，请求顺序保留，变更的卡片获得单独的未读指示器。
- 原始人工请求和源记录披露仍可访问。读取合成提示源会显示原始文本。恶意测试夹具贡献者文本呈现为文本而非可执行标记。
- 搜索 `viewer` 会同时限定请求计数、状态计数和交接队列。最新构建还显式暴露 Other 状态，并在存在多个项目时显示项目选择器；聚焦的呈现回归测试覆盖了这些最终新增内容。
- **Connect ChatGPT** 打开一个可选设置对话框，包含现有的 `https://cmem.ai/connect?from=local-work` 目标和共享范围文案。打开或关闭对话框不会连接账户或发送记忆。
- **Copy handoff** 的成功路径也由发布负责人检查。独立地，失败路径通过 Chrome DevTools 控制台（经 CUA 操作）在隔离的测试夹具标签页中临时使 `navigator.clipboard` 拒绝来验证。点击 Copy handoff 显示了明确的剪贴板不可用消息，以及一个可见、聚焦、只读的文本区域。全部 422 个字符均被选中并可手动复制。重新加载清除了临时测试覆盖。

## 响应式测量

原生 Chrome 窗口调整大小能力最初停在 521 CSS px。这未被当作 390 px 测试。最终窄屏检查使用 Chrome 的设备工具栏（经 CUA 操作），并对最终重建的资产进行只读 DOM 测量：

| 实际视口 | 文档滚动宽度 | 最远卡片右边缘 | 结果 |
| --- | --- | --- | --- |
| 390 × 652 CSS px | 390 px | 368 px | 无水平页面溢出 |
| 320 × 652 CSS px | 320 px | 298 px | 无水平页面溢出 |

原生设备工具栏将可用模拟高度保持在 652 px；这些最终检查不声称 844 px 高度。状态标签在窄宽度下保留各自的水平滚动。剪贴板失败对话框也在 320 px 下测试，未加宽文档。桌面交互检查在 1463 CSS px 宽度下运行。

设备模拟已禁用，临时剪贴板覆盖已通过重新加载移除，隔离的测试标签页在验证后关闭。

## TeamBrain 共享工作区验证

独立验证于 2026 年 10 月 17 日，针对 `http://127.0.0.1:37865/` 的隔离、代表性 TeamBrain 测试夹具。该测试夹具使用云合约的已认证本地模拟；这些检查未加入真实团队、更改共享或创建检出。

- 初始 My Work 视图保留五个个人请求，In progress、Needs you、Ready to check、Checked 和 Other states 各有一个请求。
- 选择 TeamBrain 显示两个共享列表和两个开放任务、示例团队的五席中三席计数，以及明确声明此计算机的共享已关闭。返回 My Work 保留其独立的五请求数据和计数。
- 展开共享任务及其嵌套冲突发现会显示记录的下一步操作和说明。共享工作不暴露个人审查变更控件。
- 直接加载 `/#teambrain` 会选择并加载共享工作区。
- 在实际 `window.innerWidth` 为 320 CSS px 时，文档滚动宽度也是 320 px。品牌、工作区导航、成员控件、卡片和展开的任务保持可读，无水平页面溢出。验证后临时浏览器视口覆盖已重置。
- 代码审查发现一个共享范围呈现问题：空项目数组必须表示未选择项目，而只有 `null` 表示所有项目。该区别已在最终 QA 前纠正并由回归测试覆盖。

独立运行共享客户端、TeamBrain 路由和查看器头部套件通过了全部 38 个测试。实现负责人还报告最终构建、类型检查和全部 134 个目标测试通过。在审查的合约、隐私分离、请求竞态或浏览器行为中未发现遗留阻塞问题。
