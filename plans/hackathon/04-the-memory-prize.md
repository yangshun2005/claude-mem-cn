## 一句话说清 Claude-Mem 是什么

Claude-Mem 是面向 AI 编程智能体的开源记忆层。第二个智能体观察你的主智能体工作，把发生的事转成结构化、带时间戳的观察记录，并使其可搜索——于是下一次会话开局就是热的，而不是冷的。已有 10 万+ 开发者使用。

机制用大白话说：你的主智能体执行动作——读文件、改文件、跑命令。每个动作都交给第二个"观察者"智能体。观察者问"这值得记一笔吗？"大多数时候不值得。值得时，它写一条结构化笔记：一个**标题**、一个**副标题**、几条**单句事实**（可独立成立的语义块）、一段简短**叙述**、一个**分类**（bugfix、feature、decision、discovery……）、若干**标签**、涉及的**文件**，以及一个**时间戳**。笔记存在本地、带语义理解的搜索索引里。下次会话，标题以时间线形式返回；详情只在需要时按 ID 取。观察者的职责描述——即**模式**——可替换，所以同一套机制能观察代码、邮件、照片、转录文本、机器人日志，任何东西。

## 挑战

**构建一个真正能记住东西的智能体工具。**

不是"上下文窗口更大的智能体"。不是"把所有东西塞进提示词的智能体"。而是一个智能体——或给智能体用的工具——它保留重要的东西，在相关时找得到，并用它让自己比上次更快、更聪明、更有用。

Claude-Mem 给你记忆层。你来构建让记忆*真正起作用*的东西。

## 七个方向

选一个、组合几个，或自带想法。

### 1. 热启动
一个开局就有即时上下文的智能体，而不是把前十个回合烧在重新发现代码库上。量化它：冷启动版本要多少回合才有用？你的要多少？把差距展示出来。

### 2. 基于时间线构建
把时间线和记忆搜索技能当作你的检索层，去做点新东西。时间线是按时间排序的结构化笔记流，每条带 ID——锚定任意一条，读它前后发生了什么。搜索支持语义和关键词，可按项目、分类、日期过滤。如果拿这个当数据库，你会构建什么？

### 3. 给技能一个界面
仓库里的技能是 CLI 形态：文本进，文本出。用 UI 或 UX 把它们包起来，让记忆变得**看得见**、**可操控**、**可分享**。一个仪表盘。一个浏览器扩展。一个移动端视图。一种编辑或批准笔记的方式。一种把记忆交给队友的方式。

### 4. 构建集成
把 Claude-Mem 接入它还没去过的地方——你的编辑器、CI 流水线、聊天应用、另一个智能体框架或运行环境。记忆在工作实际发生的地方最有价值。

### 5. 什么都能摄入，什么都能找
观察记录不限于文本——Claude-Mem 也能接收图像，所以截图、UI 截屏、设计文件和白板照片，与转录文本、日志、Issue、提交历史、支持工单一样可用。自定义模式告诉观察者该关注什么。任意数据进，任意模式出。`/mode-creator` 会采访你并写出模式。

### 6. 看到就触发
智能体工作时，观察记录实时落地。基于它们挂接动作：某个模式出现，就运行点什么。一条安全笔记落地 → 通知频道。出现一条"decision"观察 → 开一张工单。同一个错误被观察到三次 → 升级。智能体对刚发生的事做出反应，而不是等着被问。

### 7. 记忆即速度
用回忆来削减 token、回合数或实际耗时。标题优先的回忆模式已报告启动上下文节省约 99%；再往前推，量化它，把数字亮出来。

## 速查表回顾

- **两个智能体：** 构建者干活；观察者记笔记。
- **每次工具调用**都交给观察者；它决定记 / 不记。
- **一条笔记 =** 标题 + 副标题 + 单句事实 + 叙述 + 分类 + 标签 + 文件 + 时间。
- **回忆 =** 先标题（时间线）→ 按 ID 取详情 → 其余靠搜索。
- **模式 =** 观察者可替换的职责描述：代码、邮件、照片、转录文本、机器人，任何东西。
- **可基于：** 时间线 · 搜索 · 技能 · 实时观察 · 会话摘要 · 模式。
